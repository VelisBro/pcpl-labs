# Рубежный контроль 2

Рефакторинг РК-1, вариант 21, запросы А. Вычисления возвращают результаты,
получают данные через параметры и не зависят от консольного вывода.
Модели — неизменяемые `dataclass`. Используется стандартный TDD-фреймворк `unittest`.

Из корня репозитория:

```bash
python3 -m rk_02.solution
python3 -m unittest rk_02.test_queries -v
```

Ровно **3 тестовых метода**: А1, А2, А3. Проверяются эталонные результаты,
сортировка, пустые коллекции и группы, одинаковые суммы, независимая связь M:N,
регистр и отдельное слово «язык». Реальный запуск сохранён в `results/tests.txt`.
