# Лабораторная работа 5

Разработка простого бота для Telegram с использованием языка Python.

Бот «Учебный ежедневник» принимает расписание текстом или TXT, показывает занятия
кнопками «Сегодня», «Завтра», «Неделя», отправляет их ежедневно в выбранное время.
ЧС/ЗН чередуются относительно указанного понедельника числителя. Данные хранятся в SQLite.

## Запуск

Из корня репозитория после установки `requirements.txt`:

```bash
python telegram_labs/launch.py --lab 5
```

Первый запуск попросит новый токен BotFather скрытым вводом. Останови ЛР 6 перед
запуском ЛР 5 с тем же токеном. В боте отправь `/start`: готовое расписание ИУ5-32Б
подключится автоматически, бот покажет занятия текстом и включит отправку на 08:00.
Нажми «Сегодня» или напиши «расписание», чтобы получить занятия на день отправки запроса.
Для другого расписания используй `/upload`. В этой версии загрузка сохраняется сразу,
без конечного автомата и шага подтверждения. При загрузке сохраняется выбранное время.

Проверка без токена и сети:

```bash
python -m pytest lab_05 -v
python -m telegram_labs.demo 5
```
