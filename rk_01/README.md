# Рубежный контроль 1

Вариант предметной области **21: Оператор — Язык программирования**.
Запросы **А**, выбраны пользователем.

```bash
python3 rk_01/main.py
```

Команда выполняется из корня `pcpl-labs`, Python 3.10+, внешних зависимостей нет.

- А1: операторы и основные языки, сортировка по языкам.
- А2: языки с суммарным числом операндов операторов, по убыванию суммы.
- А3: языки, содержащие отдельное слово «язык», и их операторы по связи M:N.

«Сотрудник» из шаблона условия заменён оператором, «отдел» — языком,
«зарплата» — арностью, слово «отдел» — словом «язык».
Основной язык в 1:N — учебное распределение, не утверждение о происхождении оператора.
Тестовые коллекции содержат 4 оператора, 3 языка и 5 связей.
При равных значениях сортировка дополнена названием для воспроизводимости.
А2 исключает пустые группы, как пример преподавателя.
