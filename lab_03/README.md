# Лабораторная работа 3

Функциональные возможности языка Python Часть 1

Реализовать генераторы, итератор с удалением повторов и сортировку с функцией ключа. Работа содержит задачи 1–4 общего задания №3–4.

## Запуск

Команды из корня репозитория после установки `requirements.txt`:

```bash
python lab_03/lab_python_fp/field.py
python lab_03/lab_python_fp/gen_random.py
python lab_03/lab_python_fp/unique.py
python lab_03/lab_python_fp/sort.py
```

Проверка: `python -m pytest lab_03 -v` — 3 проверок.

ЛР 3 и 4 образуют общее задание из семи задач. Для полной работы пакета сохраняйте обе папки.
