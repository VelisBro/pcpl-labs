# Лабораторная работа 1

Основные конструкции языка Python

Разработать три консольные программы для решения биквадратного уравнения и сравнить процедурную, объектно-ориентированную и функциональную парадигмы.

## Запуск

Команды из корня репозитория после установки `requirements.txt`:

```bash
python lab_01/procedural.py 1 -5 4
python lab_01/object_oriented.py 1 -5 4
python lab_01/functional.py 1 -5 4
```

Проверка: `python -m pytest lab_01 -v` — 31 проверок.
