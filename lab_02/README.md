# Лабораторная работа 2

Объектно-ориентированные возможности языка Python

Изучить абстрактные классы, наследование, композицию, свойства и методы класса на примере геометрических фигур.

## Запуск

Команды из корня репозитория после установки `requirements.txt`:

```bash
python lab_02/main.py --variant 21
```

Проверка: `python -m pytest lab_02 -v` — 7 проверок.
