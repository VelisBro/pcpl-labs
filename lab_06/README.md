# Лабораторная работа 6

Шаблоны проектирования и модульное тестирование в Python

Реализовать порождающий шаблон Factory Method для сервиса уведомлений и проверить его с помощью pytest, pytest-bdd и Mock.

## Запуск

Команды из корня репозитория после установки `requirements.txt`:

```bash
python lab_06/main.py
python -m pytest lab_06 -v
```
