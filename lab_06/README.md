# Лабораторная работа 6

Разработка бота на основе конечного автомата для Telegram с использованием языка Python.

Бот «Учебный ежедневник» расширяет ЛР 5 пошаговой настройкой.
Конечный автомат реализован через `ConversationHandler` и содержит ровно три состояния:

| Состояние | Ввод | Успех | Ошибка |
|---|---|---|---|
| SCHEDULE | Расписание текстом или TXT | REMINDER_TIME | Остаться в SCHEDULE |
| REMINDER_TIME | Время ЧЧ:ММ | CONFIRM | Остаться в REMINDER_TIME |
| CONFIRM | Сохранить или Отмена | Запись в SQLite и END либо отмена и END | Остаться в CONFIRM |

`/cancel` и `/start` завершают диалог из любого состояния. END — выход из автомата,
главное меню работает вне диалога. До подтверждения прежние данные не меняются.
`/upload` перезапускает ввод. Черновики пользователей раздельны.

## Запуск

Из корня репозитория после установки `requirements.txt`:

```bash
python telegram_labs/launch.py --lab 6
```

На Mac можно открыть `start_diary.command` двойным щелчком. При первом старте
появится скрытый запрос нового токена BotFather. Не запускай ЛР 5 одновременно.

В боте: `/start` → `/template` → «Загрузить расписание» → отправить TXT → `07:00` →
«Сохранить». Затем доступны кнопки «Сегодня», «Завтра», «Неделя» и настройки рассылки.

Проверка без токена и сети:

```bash
python -m pytest lab_06 -v
python -m telegram_labs.demo 6
```
