# Домашнее задание на Rust

Небольшой проект **«Анализатор оценок»**. Rust выбран для изучения нового языка.
В официальном условии ДЗ номер варианта не используется; номер 21 относится к РК.

Программа читает UTF-8-файл, строит рейтинг по среднему баллу и частоты оценок.
Демонстрируются владение, заимствование, структуры, `impl`, перечисления,
`Result`, `match`, `?`, замыкания, итераторы, модули и встроенные тесты.

## Запуск на этом Mac

Из корня `pcpl-labs`:

```bash
./homework/cargo-local.sh run --offline -- data/students.csv
./homework/cargo-local.sh test --offline
./homework/cargo-local.sh run --offline -- data/invalid.csv
```

Rust установлен отдельно в `~/.local/share/pcpl-rust/`, настройки shell не менялись.
Скрипт автоматически выбирает обычный Cargo, если тот доступен, или эту установку.
Проект можно открыть в VS Code через меню **Файл → Открыть папку → homework**.

## На другом компьютере

Установить Rust/Cargo по [официальной инструкции](https://rust-lang.org/tools/install/).
Затем из `homework/`:

```bash
cargo run --offline -- data/students.csv
cargo test --offline
cargo fmt --check
cargo clippy --offline --all-targets -- -D warnings
```

Нет сторонних зависимостей. Для format/lint нужны компоненты rustfmt и clippy.

## Формат данных

```text
Иванов;5;4;5
Петров;3;4;3
```

Это простой формат с `;`, без заголовка и CSV-кавычек. Оценки — целые 2..5.
Пустые строки и комментарии `#` пропускаются, пробелы по краям удаляются.
Повторные фамилии отвергаются: в этом учебном проекте фамилия служит ключом.
Регистр значим. Среднее считается по исходным целым оценкам, округление до двух
знаков применяется только при выводе. Рейтинг: средний балл по убыванию,
затем фамилия по порядку строк Rust. Невалидная строка отвергает весь файл.
Ошибка записывается в stderr, процесс возвращает код 1; успешный запуск — 0.
