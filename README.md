## Установка

Python 3.10 или новее. Все команды выполняются из корня репозитория.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В Windows: `py -m venv .venv`, затем `.venv\Scripts\activate`.

## Запуск

```bash
python lab_01/procedural.py 1 -5 4
python lab_01/object_oriented.py 1 -5 4
python lab_01/functional.py 1 -5 4
python lab_02/main.py --variant 21
python lab_03/lab_python_fp/field.py
python lab_03/lab_python_fp/gen_random.py
python lab_03/lab_python_fp/unique.py
python lab_03/lab_python_fp/sort.py
python lab_04/lab_python_fp/print_result.py
python lab_04/lab_python_fp/cm_timer.py
python lab_04/main.py lab_04/data/demo.json --seed 21
python lab_04/main.py lab_04/data/jobs.json --seed 21
python -m pytest lab_05 -v
python lab_06/main.py
python -m pytest -v
```

Для запуска `process_data.py` как модуля добавьте обе папки в PYTHONPATH:
`PYTHONPATH=lab_03:lab_04 python -m lab_python_fp.process_data lab_04/data/demo.json --seed 21`.
Переносимый запуск без настройки PYTHONPATH — через `lab_04/main.py`.

В ЛР 1 пропущенные и некорректные коэффициенты запрашиваются повторно. Выводятся
только действительные корни, включая вырожденные случаи. Используются конечные
числа Python float; это учебный численный алгоритм, без произвольной точности.

ЛР 6 моделирует отправку уведомления выводом в поток. Никакие SMS и письма не отправляются.

## Проверка

Набор содержит 61 тест. В ЛР 5 — четыре теста pytest и три сценария pytest-bdd;
в ЛР 6 — шесть тестовых случаев pytest и три сценария pytest-bdd. Mock проверяет
повторный ввод, запись в поток и ошибки записи. Тесты изолированы от сети.
Реальные журналы находятся в `results/` каждой работы и в `validation/`.

GitHub Actions запускает тот же набор на Python 3.10, 3.12 и 3.13 после публикации.
Локально проверена версия Python, указанная в `validation/environment.txt`.
