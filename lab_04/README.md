# Лабораторная работа 4

Функциональные возможности языка Python Часть 2

Реализовать декоратор, два контекстных менеджера и конвейер обработки вакансий. Работа содержит задачи 5–7 общего задания №3–4.

## Запуск

Команды из корня репозитория после установки `requirements.txt`:

```bash
python lab_04/lab_python_fp/print_result.py
python lab_04/lab_python_fp/cm_timer.py
python lab_04/main.py lab_04/data/demo.json --seed 21
python lab_04/main.py lab_04/data/jobs.json --seed 21
```

Проверка: `python -m pytest lab_04 -v` — 4 проверок.

ЛР 3 и 4 образуют общее задание из семи задач. Для полной работы пакета сохраняйте обе папки.
